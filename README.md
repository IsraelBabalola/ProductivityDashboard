# Personal Productivity Dashboard

A full-featured productivity dashboard built with Next.js and TypeScript. 
Tracks tasks, habits, and notes with streaks and localStorage persistence.

## Features
- Tasks: add, delete, mark complete
- Habits: daily streak tracking
- Notes: add and organize notes
- Home page dashboard summary

## Run Locally
1. Clone repo
2. `npm install`
3. `npm run dev`
